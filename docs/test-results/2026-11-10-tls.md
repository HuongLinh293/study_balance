# Kết quả kiểm thử TLS ở gateway — 10/11/2026

Môi trường: Docker Compose, Nginx 1.30 (stable-alpine), chứng chỉ tự ký do `gateway-cert` tạo. Cách cấu hình: [README](../../README.md#chạy-toàn-bộ-bằng-docker).

| # | Kịch bản | Kết quả |
|---|---|---|
| 1 | `gateway-cert` lần đầu tạo chứng chỉ; chạy lại thì giữ nguyên | Đạt. RSA 2048, SHA-256, SAN `localhost`, `127.0.0.1`, `::1`, hạn 825 ngày |
| 2 | `curl --cacert tls.crt https://localhost:8443/api/user/health` | 200, HTTP/2 |
| 3 | Phiên bản TLS (`openssl s_client`) | TLS 1.1 bị từ chối; TLS 1.2 (ECDHE-RSA-AES256-GCM-SHA384) và TLS 1.3 (TLS_AES_256_GCM_SHA384) đạt |
| 4 | Client không tin cậy chứng chỉ | Bị từ chối (đúng với chứng chỉ tự ký) |
| 5 | `http://localhost:8088/...?x=1` và `POST` qua HTTP | 308 sang `https://localhost:8443/...`, giữ đường dẫn, query và phương thức |
| 6 | Cookie refresh khi đăng ký qua HTTPS | `HttpOnly; Secure; SameSite=Strict; Path=/api/user/auth` |
| 7 | `/api/task/metrics` qua HTTPS | 404 (vẫn chặn) |
| 8 | Callback OAuth qua HTTP và HTTPS có `code` | Chuyển hướng/xử lý bình thường; 0 dòng log gateway chứa `code` |
| 9 | `npm run test:e2e` qua HTTPS (tin cậy chứng chỉ bằng `NODE_EXTRA_CA_CERTS`) | 15/15 bước đạt |
| 10 | `npm run test:outage` qua HTTPS | Đạt |

Phát hiện khi kiểm thử và đã sửa: server HTTP mới (chỉ chuyển hướng) ban đầu ghi access log cho cả callback OAuth, làm lộ authorization code của redirect URI cũ. Đã tắt log cho hai đường callback ở server này.

Chưa làm: trình duyệt vẫn cảnh báo chứng chỉ cho đến khi người dùng tin cậy `tls.crt` hoặc dùng mkcert. TLS chỉ có ở gateway; giữa gateway và các service, với MySQL và RabbitMQ trong mạng Docker vẫn là kết nối thường, trừ replication MySQL đã dùng TLS.
